# 쎈 공통수학2 문항 변환 규칙

출력: JSON 배열. 문항 하나 = 객체 하나. 필드는 예시.json 과 동일하게.

- id: "SSEN-공수2-0016" (번호 4자리)
- source: "시중교재", book: "쎈 공통수학2 (22개정)", page: 문제 본책 페이지 번호(정수), num: "0016"
- unit: "공수2-1-01", unitName: "도형의 방정식 › 평면좌표"
- type: 교재에 적힌 유형명 그대로 (예: "두 점 사이의 거리", "같은 거리에 있는 점"). A단계 기본 다잡기(0001~0015)는 그 위 개념 제목(예: "두 점 사이의 거리", "선분의 내분점") 사용. C단계 실력 굳히기는 해설지에 적힌 유형명을 쓰고, 없으면 가장 가까운 유형명.
- level: 번호 옆 표시 기준 — 하 / 중 / 상 / 최상 (A단계 기본 다잡기는 "하"). "서술형" 표시는 kind에 반영.
- kind: "객관식"(①~⑤ 보기 있음) / "주관식" / "서술형"(서술형 표시가 있을 때)
- body: 문제 본문. 수식은 $...$ (LaTeX). 점은 $\mathrm{A}(3,\,3)$, 선분은 $\overline{\mathrm{AB}}$, 분수는 \dfrac. "오른쪽 그림과 같이" 같은 문구는 그대로 둠. 보기(①~⑤)는 body에 넣지 말고 choices에.
- choices: 객관식이면 5개 문자열 배열(각각 $..$), 아니면 [].
- answer: 객관식은 "①"~"⑤", 주관식은 값 문자열(예: "5", "$\sqrt{10}$"). 해설지 끝의 답 표시 기준.
- figure: 그림이 있으면 {"page": 본책페이지, "half": "L"|"R", "bbox": [x1,y1,x2,y2]} — img/q-0XX_L.png 또는 _R.png 이미지 기준 픽셀 좌표(이미지 크기 약 577×1520). 여유 있게 10px 정도 넓게. 그림 없으면 null. 그림 안의 글자(좌표 라벨)는 body에 옮기지 않음.
- solution: 해설지 풀이 전체. 줄바꿈 유지. 디스플레이 수식은 $$...$$ 한 줄. "다른 풀이"는 **다른 풀이** 로 시작. 서술형 채점 기준표는 마크다운 표(| 채점 기준 | 비율 |). 해설의 ㉠㉡, ❶❷ 기호 유지. 마지막 답 표시(답 ②)는 solution에 넣지 않고 answer에만.
- parent: "" (원본)

원칙
- 문제 번호(0001~)가 본책과 해설지에서 같음. 반드시 같은 번호끼리 매칭.
- 글자 하나, 부호 하나 틀리지 않게. 확실하지 않은 글자는 추정하지 말고 "[불확실: ...]"로 표시.
- 문항 하나도 빠뜨리지 말 것. 범위 안의 모든 번호가 들어 있어야 함.
