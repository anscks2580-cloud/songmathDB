# 변형문제 생성 규칙 (쎈 공통수학2 1단원)

입력: out/batch_X.json 의 원본 문항. 출력: 원본 하나마다 변형 3개 (쉬운 버전 / 비슷한 버전 / 어려운 버전).

각 변형 객체의 필드 (원본과 동일 구조):
- id: 원본 id + "-E1" / "-S1" / "-H1"   (예: SSEN-공수2-0016-S1)
- num: 원본 num + "-E1" / "-S1" / "-H1"
- parent: 원본 id
- variant: "easy" / "similar" / "hard"
- source: "자체제작", book: "자체제작", page: ""
- unit, unitName, type: 원본과 동일
- level: easy → 원본보다 한 단계 아래(하→하, 중→하, 상→중, 최상→상), similar → 원본과 같음, hard → 한 단계 위(하→중, 중→상, 상→최상)
- kind: 객관식/주관식 자유롭게 선택 가능. 객관식이면 choices 5개(정답 하나만 맞아야 하고, 오답은 흔한 실수 결과로 그럴듯하게). 주관식이면 choices [].
- body, choices, answer, solution: 규칙은 변환규칙.md 와 동일(수식 $..$, 점 $\mathrm{A}(1,\,2)$, 선분 $\overline{\mathrm{AB}}$, 디스플레이 수식 $$..$$).
- figure: 그림이 꼭 필요하면 원본 그림을 그대로 쓸 수 있을 때만 "=parent" (원본과 똑같은 도형·좌표일 때). 그 외에는 null 로 두고 그림 없이 풀 수 있게 문제를 서술하라.

변형 기준
- 쉬운 버전: 같은 유형·같은 풀이 구조. 수치를 단순하게(정수, 작은 수), 조건을 하나 줄이거나 직접 묻는 형태로.
- 비슷한 버전(쌍둥이): 풀이 구조 완전히 동일, 숫자·점의 좌표·비율만 바꿈. 답이 깔끔하게 떨어지도록 숫자를 고를 것.
- 어려운 버전: 같은 유형이지만 조건을 하나 더 붙이거나(미지수 추가, 다른 개념 결합: 최솟값, 자취, 삼각형 모양 판정 등) 역으로 묻는 형태. 1단원(평면좌표) 범위 안에서.
- 세 변형 모두 **반드시 직접 풀어서 답을 검산**하고, 해설은 원본 해설 수준으로 단계별로 쓴다. 답이 복잡한 무리수·분수가 되면 숫자를 바꿔서 깔끔하게 만든다.
- 문제 문장은 교재 문체(~일 때, ~의 값은?, ~를 구하시오.)를 따른다.
