## 교재 구조
- **유형편** (img/u-0PP.png, PP=PDF 쪽수): 한 쪽에 문항 3개(유형연습 ①②③…번호는 단원 안에서 1부터 이어짐). **한 쪽 = 유형 하나**. 단원 첫 쪽이 유형 1, 둘째 쪽이 유형 2 … (유형 n 쪽의 문항 번호는 3n-2, 3n-1, 3n). 풀이는 img/us-1PP.png 에 번호 순으로 2단 배치.
- **개념편** (img/g-0PP.png): 단원 앞 2~4쪽이 "세쌍둥이 필수개념"(개념 정리), 그다음 "유형별 필수예제"(한 쪽 3문항, 필수예제 n = 유형 n 의 대표 문제이며 유형편의 유형연습 3n-2 와 같은 문제), 그다음 "세쌍둥이 연습문제"(한 쪽 4문항, 2단). 풀이는 img/gs-1PP.png.
- 유형명이 교재에 적혀 있지 않다. **유형 n 의 이름을 네가 붙여야 한다**: 쎈유형목록.txt 가 아직 없는 단원이니 쎈 공통수학1 5단원(이차방정식과 이차함수) 유형명을 쎈 문체로 짓되(예: "이차함수의 그래프와 x축의 위치 관계", "이차함수의 그래프와 직선의 위치 관계", "이차함수의 최대·최소", "제한된 범위에서의 이차함수의 최대·최소", "이차함수의 최대·최소의 활용"), 같은 유형이 있으면 그 이름을 그대로 쓰고(가장 중요), 없으면 쎈 문체로 짧게 짓는다(예: "다항식의 연산; 미지 다항식 구하기"). 수식은 평문(x²+y²)으로.

## 문항 JSON 필드 (예시.json과 같되 아래 값)
- id: 유형편 "FAN-공수1-U{단원}-{번호3자리}" (예 FAN-공수1-U1-007), 개념편 필수예제 "FAN-공수1-G{단원}-E{번호2자리}", 연습문제 "FAN-공수1-G{단원}-P{번호2자리}"
- source: "학원교재", book: "세쌍둥이 유형편 공통수학1" 또는 "세쌍둥이 개념편 공통수학1", page: PDF 쪽수, num: "U1-007" / "G1-예제01" / "G1-연습01"
- unit / unitName: 이번 장은 세쌍둥이 "Ⅱ. 방정식과 부등식 02. 이차방정식과 이차함수"(세쌍둥이 4번째 장이므로 id의 단원 번호는 4: U4-…, G4-…). unit 코드는 쎈 기준 "공수1-2-05" / unitName "방정식 › 이차방정식과 이차함수". 단, 문항 내용이 이차방정식만 다루면(이차함수 없음) "공수1-2-04" / "방정식 › 이차방정식".
- type: 네가 붙인 유형명(표준 유형). fanType: 유형 번호(정수). 연습문제는 가장 가까운 유형 번호·이름을 붙인다. stdType: type과 동일.
- level: 유형편·필수예제 "중", 연습문제 "상" (표시가 없으므로 고정)
- 그래프 그림이 있는 문항은 figure bbox(전체 쪽 이미지 기준, half "F")를 반드시 지정한다.
- kind: ①~⑤ 보기 있으면 객관식, 아니면 주관식. choices, answer, body, solution, figure(그림 있을 때만 {"page","half":"F","bbox"} — 전체 쪽 이미지 기준 픽셀, 없으면 null), parent "", variant ""
- solution: 풀이 전체. 맨 앞의 답(예: "2x²-2xy+y²")은 answer에, 나머지 풀이를 solution에.

## 출력
- 문항: out/<지시받은 파일명>.json (JSON 배열, UTF-8)
- 유형명 목록: out/<지시받은 파일명>_types.json — [{"n":1,"name":"...","ssen":"쎈 유형명 또는 null"} …]
- (개념편 담당만) 개념 정리: out/<파일명>_concepts.json — [{"unit":"공수1-1-01","title":"1. 다항식의 덧셈과 뺄셈","body":"마크다운+LaTeX 본문"} …] 소제목(1., 2., 3. …)마다 하나. 공식·설명을 빠짐없이, 수식은 $..$ / $$..$$.
- 저장 후 python3 으로 읽어 개수·번호를 확인하고, 문항 수·유형명 목록·불확실 표시한 곳을 보고하라. 글자·부호 하나 틀리지 않게, 모든 이미지를 Read 로 직접 확인할 것.
