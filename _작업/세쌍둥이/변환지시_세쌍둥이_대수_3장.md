## 문항 JSON 필드 (예시.json과 같되 아래 값)
- id: 유형편 "FAN-대수-U3-{번호3자리}" (예 FAN-대수-U3-007), 개념편 필수예제 "FAN-대수-G3-E{번호2자리}", 연습문제 "FAN-대수-G3-P{번호2자리}"
- source: "학원교재", book: "세쌍둥이 유형편 대수" 또는 "세쌍둥이 개념편 대수", page: PDF 쪽수, num: "U3-007" / "G3-예제01" / "G3-연습01"
- unit "대수-1-03", unitName "지수함수와 로그함수 › 지수함수"
- type: 네가 붙인 유형명(표준 유형). fanType: 유형 번호(정수). 연습문제는 가장 가까운 유형 번호·이름을 붙인다. stdType: type과 동일.
- level: 유형편·필수예제 "중", 연습문제 "상" (표시가 없으므로 고정)
- kind: ①~⑤ 보기 있으면 객관식, 아니면 주관식. choices(객관식 5개, 아니면 []), answer, body, solution, figure, parent "", variant ""
- figure (**이 단원은 그래프가 많다**): 그래프·도형 그림이 있는 문항은 반드시 {"page":PDF쪽수,"half":"F","bbox":[x1,y1,x2,y2]} — 전체 쪽 이미지(910×1287) 기준 픽셀, 10px 여유. 없으면 null. 좌표축 라벨(x, y, O)과 그래프 라벨이 잘리지 않게 잡고, PIL로 잘라 Read로 확인할 것. 박스 조건·보기 ㄱㄴㄷ 박스는 그림이 아니라 "> " 줄로 body에. 표는 마크다운 표. 그림 속 글자는 body에 옮기지 않는다.
- solution: 풀이 전체. 맨 앞의 답은 answer에, 나머지 풀이를 solution에. 수식은 $..$, 디스플레이는 $$..$$. 로그 $\log_a b$, 상용로그 $\log 2$, 거듭제곱근 $\sqrt[n]{a}$.
- "다음 설명 중 옳은 것을 모두 구하시오" 처럼 ①~⑤ 가 보기이지만 복수 선택인 문제는 kind "객관식", choices 5개, answer는 "①, ④" 처럼 쉼표로.
