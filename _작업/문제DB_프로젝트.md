## 4. 작업 절차 (한 단원 기준)
1. 본책 PDF에서 단원 범위 페이지를 130dpi로 렌더링해 좌/우 반으로 나눈 이미지(`img/q-0XX_L.png`), 해설 PDF도 같은 방식(`img/s-0XX_L.png`)
2. 20문항 안팎씩 묶어 **하위 에이전트 4개 병렬**로 변환 → `out/batch_X.json` (규칙: `변환규칙.md`, 예시: `예시.json`)
3. (변형 단계일 때) 각 묶음에 대해 변형 3종 생성 에이전트 → `out/variants_X.json` (규칙: `변형규칙.md`). 반드시 sympy로 답 검산.
4. `build4.py <결과json이름> [합쳐서 보여줄 기존 결과 json …]` 실행 → 그림 bbox를 `big/q-PPP.png`(300dpi)에서 잘라 base64로 넣고 병합 → 결과 json + 시범 HTML 재생성 (build3.py는 공수2 1단원 때 쓴 구버전)
5. 검사: id 중복, parent 누락, `$` 짝, 객관식 보기 5개, 답 존재. 표본 문항을 원본 이미지와 대조.
6. 결과를 `문제DB\결과\<교재>\` 에 저장하고 `진행표.md` 갱신
7. `python3 _작업/현황.py` 실행 → 진행표 끝의 "## 현황" 표(교재별 완료 문항·진행률·남은 횟수·예상 완료일)가 자동 갱신됨. 같은 표를 `문제DB\현황.md`·`문제DB\현황.html`(더블클릭하면 브라우저)에도 저장한다. **매 작업 마지막에 반드시 이 표를 사용자에게 보여 준다.** (교재별 추정 총 문항은 현황.py의 BOOKS에서 수정)

실측 속도: 84문항 원본 변환 + 변형 252개 = 약 1시간 반(에이전트 병렬). 원본만이면 그 1/3.

level       하 | 중하 | 중 | 상 | 최상   (대표문제=중, C단계 실력굳히기=상, A단계 기본다잡기=하)

solution    해설 전체. 줄바꿈 유지, $$...$$ 디스플레이 수식, **다른 풀이**, 채점 기준표는 마크다운 표

## 5-1. 학원 자체교재(세쌍둥이) 연결 (2026-10-30 결정)
- 세쌍둥이(공수1·공수2·대수·미적분1, 각 개념편+유형편)는 `새 폴더\고등\세쌍둥이\`. 유형편은 유형별 3문항(세쌍둥이) 구조, 풀이는 유형편 PDF 끝부분에 있음. 개념편은 단원별 개념 정리 + 유형별 필수예제. 수식은 한글 수식(그림)이라 쎈과 같은 이미지 변환 방식.
- DB 필드: `source` "학원교재", `book` "세쌍둥이 유형편 공통수학1" / "세쌍둥이 개념편 공통수학1", id `FAN-공수1-U-0001`(유형편) / `FAN-공수1-G-0001`(개념편 필수예제). unit 코드는 시중교재와 동일(공수1-1-01 …).
- **세쌍둥이 유형명 = 학원 표준 유형.** 모든 문항(시중교재 포함)에 `stdType` 필드를 두어 세쌍둥이 유형명으로 매핑한다. 시중교재의 `type`(교재 자체 유형명)은 그대로 두고 `stdType`만 추가. 매핑표는 `units.json`의 각 type에 `std` 키로 기록.
- 학습지 만들기에서 세쌍둥이 문항을 고르면 같은 `stdType`의 시중교재 원본/변형 문항이 "유사 문제"로 딸려 나오게 한다(오답 보충용).
- 개념편의 개념 정리(공식·설명)도 저장: `concepts` 배열(단원 코드, 소제목, 본문 마크다운+LaTeX)로 별도 파일 `결과\세쌍둥이 공통수학1\concepts.json`. 학습지 앞장에 붙일 수 있게.
- (2026-10-30 실제 구조) 세쌍둥이 장 구성은 쎈과 다름: Ⅰ.다항식 01 다항식의 연산 / 02 나머지정리와 인수분해, Ⅱ.방정식과 부등식 01 복소수와 이차방정식 / 02 이차방정식과 이차함수 / 03 여러가지 방정식 / 04 여러가지 부등식 … 유형편은 단원당 12쪽×3문항=36문항, 쪽마다 유형 하나(유형명 없음, 번호만). 개념편은 필수개념 → 유형별 필수예제 12(=유형 n 대표, 유형편 3n-2와 같은 문제) → 연습문제 18(4문항/쪽). 풀이는 두 책 모두 뒤쪽에 단원 순(개념편은 필수예제 풀이 → 연습문제 풀이 순).
- 유형명은 교재에 없으므로 쎈 유형명과 같은 것은 그대로 쓰고 없으면 새로 지음(1~3단원 36유형 중 30개가 쎈과 동일). type=stdType. 연습문제는 가장 가까운 유형 번호(fanType)를 붙임. level: 유형편·필수예제 "중", 연습문제 "상".
- 1~3단원 결과: 유형편 108 + 필수예제 36 + 연습문제 54 = 198문항, 개념 17개(`결과\세쌍둥이 공통수학1\`). 복소수 장의 이차방정식 문항(유형 7~12)은 unit을 공수1-2-04로 넣음. units.json 각 type에 `std` 키 추가, 쎈 1~3단원 문항에 stdType 추가 완료.
- 진행 순서: 쎈과 같은 과목을 나란히 — 쎈 공수1 n단원 할 때 세쌍둥이 공수1 n단원(개념편+유형편)도 같이. 이미 끝난 1~3단원은 다음 작업 때 세쌍둥이 1~3단원을 먼저 따라잡고, 그때 쎈 1~3단원 문항에 stdType을 붙인다.
